### Physics assessment

The FS expression is the standard infinite-slope form with slope-parallel seepage when z and h_w are vertical heights: [c'+c_r+(gamma_sat z - gamma_w h_w)cos^2B tanphi']/(gamma_sat z sinB cosB). Using gamma_sat for the whole column overweights the unsaturated part (moist unit weight is about 10-15% lower). This is a minor, conservative-ish approximation; it should be stated. The serious error is applying infinite slope to SPRING DEEP-SEATED failures driven by a seasonal-high table. Infinite slope needs z/L << 1. Deep-seated slides (S24 median depth 14.6 m, #224; 10^2-10^3 m per #135) need limit-equilibrium/3-D analysis or an explicit exclusion. The claim that it 'needs no new field data' is false: inventory scoring (#129) needs an inventory, and c_r/z need literature priors.

Turn the twin's antecedent hydrology into a real landslide product. Today there is **no slope-stability physics** in the repo (`src/models/soil_mechanics.py:64` raises `NotImplementedError`), and the recharge raster the exporter hands to LandLab is generated by the **uncalibrated monthly** water budget (`src/io/landlab_export.py:265` calls `coupled_water_budget` with no `slope_tan`/`hand_m`/`dt_days`).

## MVP (physically reasonable, quickly implementable)
Infinite-slope (Montgomery-Dietrich / LandLab `LandslideProbability`) factor of safety per cell:

`FS = [c' + c_r + (gamma_sat*z - gamma_w*h_w)*cos^2(beta)*tan(phi')] / [gamma_sat*z*sin(beta)*cos(beta)]`

driven by (a) the twin's **antecedent saturation / perched head** `h_w` for FALL shallow failures and the **seasonal-high water table** for SPRING deep-seated, from the CALIBRATED DAILY budget; (b) root cohesion `c_r` as a land-cover constant; (c) colluvium thickness `z` from a slope-dependent soil-depth model. Run LandLab end-to-end on a pilot corridor and score against a landslide inventory. This is textbook, uses an existing LandLab component, and needs no new field data.
