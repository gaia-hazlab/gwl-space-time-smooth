The direction is correct. (2) The kernels the operator will 'freeze at Vs0' are not normalized and have large negative lobes (probe: sums 0.46/-0.16/0.44/0.66; at 0.71 Hz 58% of |G| is negative), so the 'kernel normalization' AC would expose an upstream codameter or usage problem. The Hertz-Mindlin exponent (Vs∝σ'^1/6 vs Hardin σ'^1/4) is itself about 50% uncertain and must be an ensemble parameter. (4) The book's k_sat has units Pa/m and a sign error (science-review S4, 03b-physics-hydromechanics.qmd:88-101). The fix must include a units table and a head-perturbation sign test. ## Problem

The operational forward and inverse paths do not currently use the same hydromechanical physics.

- The forecast path maps water state through van Genuchten capillary suction, effective pressure, Hertz–Mindlin stiffness, density, and optionally scanning hysteresis (`dvv_coupling.py`, `hysteresis.py`).
- The observation-processing / DA path first depth-inverts banded dv/v and then converts the separated signal to soil moisture and water-table change with fixed gains (`S_THETA`, `K_SAT`) in `dvv.py`.
- Forecast `Vs30(t)` is approximated by a root-depth fraction, while the seismic inversion uses frequency-dependent depth kernels.

This means a state can predict an observation through one map but be inferred from that observation through another. A closed-loop test of the small helper `forward_dvv() -> invert_dvv()` exists, but it does not close the full operational loop involving the baseline velocity profile, depth kernels, band observations, DA, and forecast products.

## Required state convention

Represent the time-dependent shear-wave velocity profile as

```math
V_s(z,t) = V_{s,0}(z) + \Delta V_s(z,t),
\qquad
m(z,t) = \frac{\Delta V_s(z,t)}{V_{s,0}(z)}.
```

`V_{s,0}(z)` is the reference/static profile (SVM, site inversion, or documented fallback). `\Delta V_s(z,t)` is generated from the evolving hydrologic and mechanical state; it is not an independent scalar shallow/deep correction.

For each observed frequency band `b`, predict the actual datum using its depth kernel:

```math
\widehat{d}_b(t)
= \int K_b(z;V_{s,0})\,
  \frac{\Delta V_s(z,t)}{V_{s,0}(z)}\,dz.
```

The first implementation may freeze kernels at `V_{s,0}`, but that approximation must be explicit and tested. Recomputing kernels as `V_s(z,t)` evolves can be a later fidelity tier.

## Proposed implementation

### 1. One shared nonlinear hydromechanical observation operator

Create a single operator used by **both** forecast prediction and inversion/DA:

```text
hydrologic + mechanical state x(t)
  -> theta(z,t), Sw(z,t), h(t), hysteresis/damage state
  -> Pc(z,t), Pe(z,t), G(z,t), rho(z,t)
  -> Vs(z,t) = Vs0(z) + dVs(z,t)
  -> depth/spatial kernels
  -> predicted banded dv/v and Vs30(t)
```

Vadose physics should use the implemented equilibrium capillary relation and scanning hysteresis consistently:

```math
P_e(z,t)=\sigma'_g(z)+\chi(S_w)P_c^{\rm eq}
        (S_w;\alpha,n,\text{wet/dry history}),
\qquad
V_s(z,t)=\sqrt{G(P_e)/\rho_b(S_w)}.
```

Do not claim the currently unimplemented dynamic-capillarity term
`\tau(S_w)\,\partial S_w/\partial t`. Add it later as an explicit operator tier, not as slide-only physics.

For the saturated zone, replace the operational `K_SAT Δh` shortcut with an effective-stress/poroelastic map where defensible. If calibration does not yet support that, retain it only as a named `linear_saturated` fidelity mode with uncertain parameters—never as a hidden inverse-only conversion.

### 2. Invert through the forward operator

The inverse should not require an algebraic “reverse petrophysics.” Evaluate the same forward operator inside the likelihood / DA update:

```math
p(x_t\mid d_t) \propto
p\!\left(d_t-H_{\rm hydroseis}(x_t);R\right)p(x_t).
```

Use ensemble evaluation for the ensemble filter, or a Jacobian of the same operator for variational/MAP tests. Retire `dvv_to_theta_change(..., S_THETA)` and `dvv_to_wtd_change(..., K_SAT)` from the operational assimilation path; keep them only as labeled diagnostic/local-linearization utilities.

This directly implements the correction requested in #165: petrophysical sensitivity is inside `H`, and uncertain petrophysical parameters are carried in the ensemble or represented in observation/model-error covariance rather than silently divided out.

### 3. Make depth and reference semantics explicit

The operator contract must carry:

- `z`, layer thickness, units, and vertical datum;
- `Vs0(z)`, reference epoch, provenance, and uncertainty;
- `DeltaVs(z,t)` and `DeltaVs/Vs0(z,t)`;
- water-table depth and the vadose/saturated transition on the same grid;
- hysteresis branch/reversal state and any mechanical damage/healing state;
- frequency-dependent vertical kernels and coda spatial footprints;
- observation reference convention (fixed, rolling, or processing ensemble).

Compute the derived velocity metric from the profile, not a depth-fraction blend:

```math
V_{s30}(t)=\frac{30\ {\rm m}}
{\int_0^{30\,\rm m} dz/V_s(z,t)}.
```

### 4. Fidelity modes

Expose and record physics modes in provenance:

1. `equilibrium_single_valued`
2. `equilibrium_hysteretic`
3. future `dynamic_capillarity`
4. `linear_saturated` (temporary)
5. future calibrated poroelastic saturated response

Forward and inverse calls for a run must use the same mode and parameter ensemble.

## Acceptance criteria

- [ ] A single `HydroSeismicObservationOperator` (name negotiable) is called by forecast and DA/inversion code; petrophysical constants are not duplicated.
- [ ] It produces `Vs0(z)`, `DeltaVs(z,t)`, `Vs(z,t)`, banded dv/v, and harmonic `Vs30(t)` with units/provenance.
- [ ] Noise-free synthetic round trip: states propagated through the full profile + kernel operator are recovered within stated identifiability/tolerance limits.
- [ ] Noisy ensemble test: posterior intervals are calibrated and contain the generating state at the expected rate.
- [ ] Wetting/drying paths with the same `theta` can yield different predicted dv/v when hysteresis is enabled, and inversion carries/conditions that state rather than selecting a single-valued curve.
- [ ] Forward forecast and DA innovations use numerically identical `H(x)` for identical state, parameters, kernels, and reference epoch.
- [ ] Tests cover sign conventions, physical bounds (`Vs>0`, bounded `theta/Sw`), depth discretization, reference changes, and kernel normalization.
- [ ] Local-linear sensitivities/Jacobians are derived from and checked against the nonlinear operator (finite-difference or autodiff directional test).
- [ ] Current shortcut functions are clearly marked diagnostic/deprecated for operational DA.
