## Why this is needed

The LandLab and liquefaction pathways already request per-cell sigma or uncertain inputs, but marginal sigmas do not preserve the joint dependence among water table, soil moisture, recharge, strength, Vs30, ShakeMap forcing, and mechanical disturbance. Hazard probabilities should be evaluated member by member from the complete posterior/forecast ensemble.

## Dependencies

- Depends on ensemble hydrologic forecast #191.
- Depends on probabilistic mechanical states #190 where damage/fire/landslide memory is used.
- Landslide path builds on #127/#128/#129/#130/#132/#133/#134.
- Liquefaction path builds on #139/#141/#142/#143/#144 and respects #140/#145/#147.
- Uses #64/#65 for export and publication conventions.
- Recommended milestone: proposed `v0.7 — Probabilistic nowcast and ensemble forecast`, with downstream acceptance in Milestones 6 and 7.

## Tasks

- [ ] Define a member-preserving hazard input contract for state, forcing, parameters, mechanical memory, masks, and native/delivered resolution.
- [ ] Run infinite-slope/LandLab calculations per joint member and report `P(FS < 1)` plus quantiles.
- [ ] Run the liquefaction susceptibility GLM per joint member and report calibrated class/threshold probabilities.
- [ ] Preserve spatial correlation and cross-variable dependence; do not independently redraw inputs from marginal sigma layers.
- [ ] Separate aleatory/scenario uncertainty from epistemic model uncertainty in metadata.
- [ ] Propagate applicability-domain and confidence masks into probabilities.
- [ ] Add tests showing that correlation changes tail probability relative to an independent-input approximation.

## Acceptance criteria

- Hazard probabilities are computed from member outcomes, not a mean-state run with post-hoc error bars.
- Member identity survives from nowcast/forecast through each hazard output.
- A deterministic one-member run reproduces the existing deterministic pathway.
- Probability products include quantiles, exceedance probability, mask, support, and uncertainty-source metadata.
- Landslide outputs are scored against held-out inventory data (#129); liquefaction remains explicitly a susceptibility screen unless #146 is implemented.
