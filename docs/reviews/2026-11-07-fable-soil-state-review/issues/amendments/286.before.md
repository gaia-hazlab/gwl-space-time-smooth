Part of the MODFLOW 6 groundwater core. Plan and design record: `docs/reviews/2026-10-18-modflow-groundwater-core/plan.md` (#273); decision issue #265. Epic: #274.

## Purpose
Score the calibrated pilot only on data it never saw, against the existing statistical GWL map
and the old store model, so the switch to MODFLOW is justified by evidence.

## Deliverable
A validation record under `docs/reviews/<date>-mf6-pilot-validation/` produced by the #236
harness: held-out wells (RMSE, bias, 90% coverage of the posterior ensemble, by HSU), recorders
(peak month, seasonal amplitude, recession constant), the pilot gauge in held-out years
(baseflow, BFI from the model hydrograph with the observation's filter). Same metrics for the
statistical Stage 1-3 map and for the store model at the same wells and years.

## Acceptance
- Every number traces to a command and a frozen manifest version.
- A negative result (MF6 not better on some metric) is reported as such, with the metric.
