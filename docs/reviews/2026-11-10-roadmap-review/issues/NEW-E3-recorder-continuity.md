# NEW-E3: Keep an event recorder running for every atmospheric river (decision and ownership)

Milestone: v0.7 Probabilistic nowcast and ensemble forecast. Labels: needs-human-decision, atmospheric.

## Purpose
#305 needs N >= 10 events with frozen issue times. Consequence feeds list only what is open now, so
an event that is not recorded while it happens is lost. One recorded event exists (November 2026).

## Deliverable
A decision by the PI with Maleen Kidiwela: who runs the recorder, where the raw archive lives,
the trigger for an event window, and the retention of forecast runs.

## Acceptance
- A written agreement on ownership and storage, linked from `ROADMAP.md`.
- The trigger rule is objective (for example an integrated-vapour-transport forecast threshold at the
  Washington coast) and is recorded before the next event.
- The #305 manifest gains a column naming the recorder window for each event.
