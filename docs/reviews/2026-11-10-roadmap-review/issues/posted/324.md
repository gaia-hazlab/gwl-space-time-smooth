# Admission contract for proxies and satellite data before they enter the filter

**Created 2026-11-11 from the roadmap review (record `docs/reviews/2026-11-10-roadmap-review/`, epic #319).**

## Purpose
The PI decision in #265 promises assimilation of raw, proxy and satellite data. Bias treatment
exists per stream (#290 "anomaly or CDF matching", #198 AR(1) bias state, #239), and no issue says
what a proxy must show before admission. The condition that a bias state is observable only against
an unbiased reference survives only in archived text. On paper no proxy in the roadmap meets all
five conditions below.

## Deliverable
`docs/proxy-admission.md` and `src/models/proxy_admission.py`: a checklist enforced in code.
1. Forward operator on the model state at native support, never an inverted retrieval.
2. R with a cited source, including representativeness and temporal correlation.
3. Declared bias treatment; a bias state only where a direct stream observes the same state inside
   the localization radius, otherwise anomalies.
4. An independent reference used to fit 2 and 3, kept out of both estimation loops.
5. A manifest role (#235) and a held-out value test, where "no value" is an accepted result.

## Acceptance
- Synthetic stream with a known AR(1) bias: recovered within its interval when the reference is
  present; declared unobservable, and refused a bias state, when absent.
- A table rating every stream in the design record's sensor table against the five conditions,
  with the owning issue or "no owner" per cell (SWE, Sentinel-1, GNSS-IR and InSAR currently have none).
- The filter refuses a stream without a passed admission record.
