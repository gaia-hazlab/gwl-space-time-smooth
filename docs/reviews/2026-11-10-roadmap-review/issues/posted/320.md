# Compute and latency budget for the cycling ensemble (measured, not projected)

**Created 2026-11-11 from the roadmap review (record `docs/reviews/2026-11-10-roadmap-review/`, epic #319).**

## Purpose
No open issue states what an N-member MODFLOW 6 (MF6) cycle costs on the full domain or how long an
operational cycle may take. #283 gives one projection from the pilot; #301 measures the land-surface
bucket only; #287 (parallel run recipe) and #289 (ensemble runner) are planned separately. Every
ensemble-size and resolution choice downstream is made blind until this exists.

## Deliverable
`docs/compute-budget.md` plus `scripts/measure_cycle_cost.py`: a measured cost table and a stated latency
target for three products (daily nowcast cycle, 15-day forecast, WY2001 to present reanalysis).

## Inputs and conventions
- Timings from the #275 fixture and the #281/#282 pilot, on a named Hyak node type, serial conda-forge
  `modflow6` build and, if #287's build exists, the PETSc build.
- Units: wall-clock seconds per member per stress period; core-hours per member-year; peak resident
  memory (GB) per member; bytes per member per restart file.
- Scaling variables recorded per run: active cells, layers, SFR reaches, solver iterations per period.

## Acceptance
- Table of measured cost at k = 1, 2, 3 (cells of 90, 180, 270 m) on the pilot, with the fitted
  scaling exponent in active cells and its residual; the full-domain figure is labelled an
  extrapolation and carries the exponent's interval.
- Cost split per cycle into: MF6 advance, land-surface advance, operators, analysis, restart I/O.
  Each term measured, none inferred by subtraction.
- A latency target stated per product with its justification (the forecast must finish before the
  next forcing run is issued), and a pass or fail against it for N = 20, 50, 100.
- If the daily cycle at N = 50 fails the target on the full domain, the document names which fallback
  is taken (larger k, one watershed model at a time, fewer layers, or the emulator of #321) and
  the issue that owns it.
