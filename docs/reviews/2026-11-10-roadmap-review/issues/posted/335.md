# One versioned hazard-facing output schema for all four consumers

**Created 2026-11-11 from the roadmap review (record `docs/reviews/2026-11-10-roadmap-review/`, epic #319).**

## Purpose
Each consumer defines its own output today. The Landlab exporter writes 2-D `.asc` with sigma in a
side file, no member and no depth axis (`src/io/landlab_export.py:42-46`); `src/io/zarr_io.py:179-180`
writes "1000 m" and "monthly" as root attributes; STAC items carry no member, lead time or version;
#187 is an internal state contract; #193 (a) mentions a shared hazard contract in one sentence of a
P2 issue; #200 defines flood terms alone. Wildfire has no contract.

## Deliverable
`docs/hazard-output-schema.md` (version 1) and `src/io/hazard_schema.py` with a validator: one
xarray/Zarr layout with dimensions `(member, issue_time, lead_time | valid_time, layer | depth, y, x)`
or `(…, reach)` for network variables, CF standard names where one exists, units, vertical datum,
spatial and temporal support, provenance (code commit, forcing run, analysis cycle), and a table of
which variables each consumer reads.

## Inputs and conventions
Variables in version 1: depth to water and layer heads; pore pressure u(z) and effective stress
sigma'(z) (from #250); root-zone water content and deficit; recharge and drainage; runoff, interflow,
baseflow per cell and per reach (#200); SWE; the forcing actually used (precipitation, temperature,
wind, vapour-pressure deficit). Marginal sigma is a derived export, never the primary object (#299).

## Acceptance
- The validator rejects a dataset with a missing `member` dimension, missing units, an undeclared
  support, or a variable name outside the registry; tests cover each rejection.
- The Landlab (#254), liquefaction (#261), flood (#200) and wildfire (#348) exports are each a
  declared view of this schema; a test round-trips a 3-member, 2-lead fixture through all four and
  member identity is preserved bit for bit.
- `zarr_io.py` root attributes are computed from the data, and the two hard-coded strings are gone.
- STAC items (#65) carry `schema_version`, member count and lead times.
