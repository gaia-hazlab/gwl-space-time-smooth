## Purpose
Measure the one-member cost of the land-surface bucket on bounded tiles with a memory preflight,
so that ensemble projections are labelled projections and never confused with a MODFLOW cycling
benchmark.

## Deliverable
`docs/reviews/2026-11-07-fable-soil-state-review/scripts/p1_bounded_performance.py` writing
`results/p1_bounded_performance.json`: preflight estimate n_cells x n_steps x 8 fields x 12 B
(abort above 8 GB); tiles 200^2, 400^2, 800^2 cells x 365 daily steps; wall time; peak RSS
(`ru_maxrss`); scaling fit and its residual; extrapolation to 1567 x 1890 cells labelled as a
projection; the dense `n_cell x n_obs` intermediate size for 2.96 M cells x 863 wells computed,
not allocated.

## Inputs and conventions
Synthetic forcing; no array written to disk; host free disk recorded.

## Acceptance
- Three separately labelled numbers: measured bucket cost per member-year; MODFLOW cost "not
  measured here (see #283)"; projected ensemble throughput with the fit residual.
- Peak RSS below the preflight cap for every tile.
- Update the TRACKER row P1 with outcome and evidence link.
