### Problems found

- Acceptance items 1 and 2 (innovation mean ≈ 0, predicted vs empirical innovation variance) are calibration targets, because B/Q/R are tuned on those same innovations. They need a held-out time block to count as validation.
- 'No visible cross-divide leakage' cannot be tested; quantify it.
- The scope claims to 'complete' #161/#163/#164/#165/#168; the dv/v parts belong to their own issues.
- Tolerances are undefined.

### Physics assessment

Physically sound. Q too small collapses the ensemble; correlated R double-counts; broad localization leaks across divides. Desroziers diagnostics are appropriate but valid only near the optimal gain, so they must be iterated. Building Q from forcing perturbations, parameter perturbations and forecast residuals risks double counting; the residual-based part should be estimated after the forcing/parameter spread is in place. prior_calibration.py implements the REML ν-profile with spatial-block CV, but per the 2026-08-20 comment it has never been run on real data.

## Why this is needed

The current demonstrations prescribe prior sigma/length scales and scalar sensor variances. The repository already improved the covariance ingredients with Matérn/region masking, OU drift variance, processing-ensemble dv/v covariance, and native-support operators, but a cycling ensemble will only be calibrated if B, Q, and R are estimated and diagnosed together.

If Q is too small, the ensemble collapses after repeated DA. If R ignores shared errors, observations are double-counted. If B/localization is too broad, sensor influence crosses divides.

## Dependencies

- Depends on #187, the cycling implementation #188, and observation records #189.
- Completes the still-open covariance aspects of #161/#163/#164/#165/#168.
- Uses calibrated static uncertainty from #186 and the coverage framework in #5.
- Coordinate with #7 for representativeness/nugget estimates and #155 for reproducible stochastic perturbations.
- Production tuning follows the scalable implementation decision in #154.

## Tasks

- [ ] Initialize ensemble B from corrected/calibrated state uncertainty rather than fixed global sigma alone.
- [ ] Estimate spatial/domain-dependent localization and prior correlation scales from held-out residuals/variograms.
- [ ] Build R blocks for shared station, reference trace, retrieval, processing, and operator errors.
- [ ] Represent petrophysical/operator uncertainty in predicted-observation ensembles or R.
- [ ] Construct Q from forcing perturbations, parameter perturbations, unresolved process error, and forecast residual statistics.
- [ ] Add innovation, normalized-innovation-squared, rank, spread-error, and Desroziers-style diagnostics where appropriate.
- [ ] Add adaptive inflation with documented bounds; do not use inflation to hide biased dynamics.
- [ ] Report covariance/diagnostic results per hydrogeologic domain and observation stream.

## Acceptance criteria

- Innovation means are statistically consistent with zero after bias handling.
- Predicted innovation variance matches empirical innovation variance within documented tolerance.
- Repeated cycling does not collapse ensemble spread or inflate it without bound.
- Adding correlated observations does not produce the overconfident result obtained by treating them as independent.
- Localization prevents visible cross-divide leakage in a synthetic terrain test.
- B/Q/R choices and tuning data are versioned and reproducible.
